MODUS ENTERPRISE AI BUILD
CHALLENGE
From Business Problem to Working Enterprise AI
Application
Purpose
This is a practical 2-day AI engineering, research and enterprise intelligence challenge.
You will not be provided with a predefined case study, dataset, architecture, process
model, database design or solution blueprint.
You are expected to independently:
Select & Define a Case → Research → Create Data → Design Architecture → Build
Backend → Build AI Intelligence → Build UI → Test → Demonstrate
The objective is to assess whether you can build an actual AI application from scratch—not
simply generate an analysis using ChatGPT or another AI interface.

Mandatory Technical Rules
Every submission must be a working application with a demonstrable architecture.
•
•

•
•
•

•

You must build the solution from scratch during the challenge and clearly identify any
pre-existing libraries/frameworks used.
All AI models, frameworks, databases, APIs and development components used for
the assignment must be free, open-source, free-tier, or locally runnable for
evaluation. No paid licence should be required to demonstrate the solution.
The application must contain a real frontend, backend, data/storage layer and
AI/model integration appropriate to the use case.
Data must persist. Refreshing or restarting the application must not simply destroy all
intelligence.
AI-generated static HTML, a PowerPoint, spreadsheet analysis, Notebook-only
demonstration or a prompt run manually through ChatGPT/Claude/Gemini is not
considered a completed AI application.
Candidates may use AI coding assistants, but must understand and explain every
major component they submit.

The application should process multiple records/cases systematically—not contain
hard-coded outputs designed only for the demo.
Outputs must be traceable to underlying data, research or reasoning wherever
applicable.
Source code and setup instructions must be submitted so the application can be
independently reviewed.

Assignment 1 — AI Transformation
Strategy Intelligence
Your Challenge
Choose a real or fictional industry and independently create an organisation facing a
significant transformation challenge.
Examples could include retail, banking, manufacturing, healthcare, logistics, telecom,
hospitality or another industry of your choice.
Do not simply ask an LLM:
“Create a transformation strategy.”
Build an AI application that researches, analyses and develops transformation
intelligence.
Your application should be capable of understanding:
Business Situation → External Change → Strategic Issues → Transformation
Opportunities → Priorities → Initiatives → Outcomes

Minimum Application Capability
A user should be able to enter or upload information about an organisation.
The backend should:
Research relevant external information where appropriate.
Store the organisation and research information.
Analyse strategic issues.
Identify evidence supporting findings.
Generate transformation opportunities.
Prioritise recommendations.
Allow users to interrogate the findings.

Demonstration Question
Your AI should be able to answer:
“What should this organisation transform, why, what evidence supports it, and what should
be done first?”
The answer must be generated from the application's underlying intelligence—not a hardcoded response.

The “Surprise Record” Test
I would make this mandatory for every assignment.
Candidates build their application without knowing the final test input.

During the presentation, the judging panel provides a new process, role, strategy, AI use
case, skill, company scenario or research question.
The candidate must enter it live.
We then observe:
Input → Backend Processing → Research/Retrieval → AI Analysis → Storage →
Relationships → Output
This immediately exposes whether someone has built an actual application or simply
prepared attractive AI-generated demo content.

Final Deliverables
Each candidate/team must submit source code repository, README/setup instructions,
architecture diagram, database/data model, model and library inventory with licences,
sample/synthetic data, research sources, working application and a 10–15 minute live
demonstration.
They should also disclose where AI coding tools were used and clearly explain what they
personally designed and implemented.
The most important judging question should be:
“If we give your application 1,000 processes tomorrow instead of 100, what happens?”
That single question will tell us a great deal about whether the candidate understands
enterprise-scale AI engineering versus simply producing an AI demo.
